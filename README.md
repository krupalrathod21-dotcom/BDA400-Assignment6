**Project:** Interactive Stock Portfolio Dashboard

## Project Overview

This project develops an interactive stock portfolio dashboard using R and Shiny. It uses historical stock market data from Yahoo Finance and applies technical analysis indicators to help visualize stock performance and trading signals.

## Stocks Analyzed

- Apple (AAPL)
- Microsoft (MSFT)
- Alphabet (GOOGL)
- Amazon (AMZN)
- NVIDIA (NVDA)

## Technologies Used

- R
- Shiny
- quantmod
- ggplot2
- TTR
- Plotly
- DT

## Technical Analysis

The project uses:

- 20-day and 50-day moving averages
- Relative Strength Index (RSI)
- Moving Average Convergence Divergence (MACD)
- Moving-average crossover trading signals (Buy, Sell, Hold)

## How to Run

1. Install R and RStudio.
2. Install the required R packages.
3. Open `Rathod_Krupal_CA_BDA400_A06.R` in RStudio.
4. Run the script to launch the Shiny dashboard.
